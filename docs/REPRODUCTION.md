## 交付限制与排错

完整交付包包含资源，Git 只包含代码。资源采用哈希校验，不从作者旧工作区寻找缺失文件。包包含固定 token 与状态样例，可先执行 render 检查画面，再跑完整 pipeline。

此次不是另一台全新机器部署验证；系统安装脚本的全部依赖安装尚未在干净环境执行。已用 pip dry-run 验证 NumPy 1.26.4/OpenCV 4.11 的解析兼容。Isaac/驱动首次启动开销取决于机器和缓存。

`doctor` 检查版本、GPU、ffmpeg 和核心分配；`prepare` 检查资源哈希。缺资源需要完整交付包，不要随意下载替代模型。若 `Runtime checksum mismatch`，使用新 runtime。若初始化/任务异常，看角色目录 `run.log`；重试用新 output。CPU 端仍需要 Isaac GPU 上下文；不宣称 CPU-only 无 GPU 机器可运行。

审查修复：兼容 NumPy 的 OpenCV 安装版本；schema 帧数与 token 数一致；参考文件缺失必须失败；失败进程 kill 后 wait 回收。5 个单元检查及 socket 收尾回归通过。
